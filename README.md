# Schiètto Hub

Portal editorial da marca **Schiètto** em [schietto.com.br](https://schietto.com.br) — redireciona para o café e para a loja de home decor.

## Destinos

- [cafe.schietto.com.br](https://cafe.schietto.com.br) — Caffè Schiètto
- [homedecor.schietto.com.br](https://homedecor.schietto.com.br) — Home Decor & Semi Jóias

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Deploy na Vercel

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Publicação

A Vercel publica o site a cada merge na `main`.
